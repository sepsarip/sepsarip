# Hi, I'm Sep Sarip Hidayattuloh 👋

I'm a **software developer** building full-stack web products and AI-powered applications I like shipping ideas end-to-end, from ML models and backend APIs to clean, usable frontends.

## 🧑🏽‍💻 About Me

- 🎓 Graduate of **Politeknik Negeri Jakarta** (Informatics Engineering)
- 🏅 **Bangkit 2024** graduate capstone [**Berongsok**](https://github.com/titii-ship-it/Berongsok)
  placed **Top 50 Best Capstone**; I built the app's dashboard & UI on the 7-person team
- 👑 Team lead of **[SARINARA-TEAM](https://github.com/SARINARA-TEAM)** — real-time smoking-detection
  system: ESP32-CAM streaming to a Raspberry Pi 5 running a computer vision model, with audio alerts
  and live web monitoring
- 🖥️ Full-stack: **React · Node.js/Express · Laravel/PHP · PostgreSQL** with Docker & CI workflows
- 🧠 ML background: TensorFlow/Keras (CNN, MobileNetV2), YOLOv8, Flask
- 📱 Also shipped Android apps in Kotlin — like the panic-button app [**GEOSOS**](https://github.com/sepsarip/GEOSOS)

## 📌 Featured Projects

- [**ATS — Applicant Tracking System**](https://github.com/sepsarip/ats-project) — my own full-stack
  monorepo: job postings, PDF CV upload with text extraction, and AI-powered match scoring via
  Sentence-Transformer & SpaCy (React, Node.js/Express, PostgreSQL, Flask, Docker)
- [**Berongsok**](https://github.com/titii-ship-it/Berongsok) — Bangkit Top-50 capstone: AI waste
  classification for trash banks with auto-pricing and dashboards (TensorFlow, Kotlin, Cloud Run)
- [**Smoking Detection System**](https://github.com/SARINARA-TEAM/web) — edge-AI computer vision:
  ESP32-CAM → Raspberry Pi 5 → CV model, with a real-time dashboard (Flask, OpenCV)
- [**Beasiswa Kampusku**](https://github.com/sepsarip/beasiswa-kampusku) — scholarship registration app
  with full validation (Laravel, Blade) BNSP certification project
- [**URL Shortener**](https://github.com/sepsarip/url-shortener) — link-shortening REST API (Node.js, Express, PostgreSQL)
- [**Kitabisa Donation Monitor**](https://github.com/sepsarip/donation-tracker) — fundraising tracker
  that alerts a Telegram bot (Node.js, Puppeteer)
- [**GEOSOS**](https://github.com/sepsarip/GEOSOS) — Android panic button sharing live location with
  emergency contacts (Kotlin)
